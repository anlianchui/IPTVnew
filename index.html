iPTV 直播源 · 影视仓订阅

基于 anlianchui/iptv2 仓库公开源整理，已剔除失效条目、升级 HTTPS、补全台标。

tvbox.json　推荐

影视仓 / TVBox 直播接口，含分组与多线路，粘贴到「配置地址」即可。

tvbox-full.json　海外可用

完整版，额外含 Bloomberg、DW 等在大陆不可达的频道。海外网络用这个。

live.m3u　带台标

标准 M3U 播放列表，适合 TiviMate、APTV、Kodi、PotPlayer 等。

live.txt　兼容性最好

「频道名,地址」纯文本，影视仓 → 设置 → 直播 → 添加直播源。

tvbox-cctv-ipv6.json　CCTV 全

CCTV-1~17 完整版（含 5 / 5+ / 6）。均为 IPv6 直连地址， 播放设备所在网络需支持 IPv6，否则会播放失败。

影视仓怎么用

  1. 打开影视仓 → 设置 → 直播（或首页顶部切到直播）
  2. 选 添加直播源 / 自定义直播，粘贴上面的地址
  3. 推荐用 tvbox.json；老版本不认 JSON 就用 live.txt
  4. 黑屏时先换个源试试，仍不行多半是当地网络到该 CDN 不通
注意：第三方源（live-ext.m3u）来自网络上流传的转发站， 项目方明确不维护、不保证可用，因此未并入推荐版。 另外直播源随时可能失效，列表中若有打不开的频道属正常现象。
